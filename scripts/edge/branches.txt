# Branches merged into edge/main by scripts/edge/rebuild.sh, in the order listed.
#
# One branch name per line, resolved against `origin` (github.com/josham/paseo).
# Blank lines and # comments are ignored.
#
# Delete a line once its PR lands upstream: the next rebuild drops the branch, and
# the change arrives through upstream/main instead. rebuild.sh warns and skips if a
# listed branch is already contained in upstream/main, so a stale line is loud rather
# than silently re-applying work upstream may have since changed.
#
# A line marked "closed upstream" will never land, so it is permanent and that hint
# does not apply to it. Upstream closes feature PRs and routes them to Discussions
# per CONTRIBUTING.md; only fixes stay open. Every feature below was closed on those
# grounds, which is why Edge exists.
#
# An author is named only where the branch re-lands someone else's PR, so you know
# who to ask about it. Unattributed lines are Josh's own — the same distinction the
# branch names already make: feat/... and fix/... are his, pr/<number>-<slug> is a
# re-land.
#
# edge/tooling is always merged first and does not belong in this list.

feat/configurable-content-width  # Content width as an Appearance setting (#3652, closed upstream)
fix/numeric-settings-clamp-resync  # Out-of-range size entries show the clamped value (#3655, open)
